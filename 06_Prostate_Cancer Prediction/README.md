# Prostate Cancer Prediction 
This project focuses on predicting prostate cancer using a medical dataset. The dataset undergoes Exploratory Data Analysis (EDA) to understand its structure, identify key features, and visualize data distributions and relationships. Various machine learning models, including Logistic Regression, Random Forest, SVM, and XGBoost, are trained and evaluated to determine the best-performing model. The code covers data preprocessing, EDA, visualization, model training, and performance evaluation, with ROC curves and AUC scores used for comparison.
