# Breast Cancer Type Prediction Using Gene Expresion
This project involves predicting breast cancer type using gene expression dataset. The dataset, sourced from Kaggle, is first subjected to Exploratory Data Analysis (EDA) to understand its structure and distribution, with various visualizations created to explore data patterns and relationships. The data is then used for training the model. The code includes data loading, EDA, visualization, model training, and performance evaluation steps.
